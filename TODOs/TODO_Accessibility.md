# Accessibility

- [ ] **Use `label` for Inputs:** Use the `label` property on `IonInput` components to properly associate labels with inputs.
- [ ] **Use Theme Colors:** Use Ionic theme colors for error messages to ensure good contrast.
- [ ] **Make "Show Password" Keyboard Accessible:** Use an `IonButton` for the "show password" icon to ensure it's keyboard accessible.
- [ ] **Improve Focus Management:** Move the focus to the error message when a login error occurs.
- [ ] **Add `label` to `IonSelect`:** Add the `label` property to all `IonSelect` components to properly associate the labels with the inputs.
- [ ] **Remove `interface="alert"` from `IonSelect`:** Remove the `interface="alert"` property from the `IonSelect` components to use the default, more accessible interface.
